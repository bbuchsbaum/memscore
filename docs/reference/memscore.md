# memscore

Native R wrappers for the `memscore` command line tools.

## Details

The package can either shell out to an external `memscore` CLI or call
the Python package in-process through `reticulate`.

Use
[`vignette("memscore", package = "memscore")`](https://bbuchsbaum.github.io/memscore/articles/memscore.md)
for a guided walkthrough.
